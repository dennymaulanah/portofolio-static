# Azeria Portfolio

A responsive and modern developer portfolio website, built using HTML5 and Tailwind CSS.

## 🚀 Key Features

- **Modern & Responsive Design**: Clean UI, utilizing glassmorphism and micro-animations.
- **Tailwind CSS**: Uses Tailwind CSS via CDN with custom color configurations for rapid development.
- **Project Detail Pages**: Each project has its own dedicated detail page (`project-detail.html`).
- **Dynamic Footer**: The copyright year is automatically updated using JavaScript.
- **Icon Support**: Uses Google Material Symbols.

## 📁 File Structure

- `index.html` - The main homepage containing the introduction, projects list, skills, and contact section.
- `project-detail.html` - A template page for displaying detailed explanations of a specific project.
- `logo.png` - The website logo and favicon (Make sure you have moved the logo image file to this directory).

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (for light interactivity)
- Google Fonts (Inter & JetBrains Mono)
- Google Material Symbols

## 💻 How to Run

1. Ensure all files (`index.html`, `project-detail.html`, and `logo.png`) are in the same folder (e.g., `c:\xampp\htdocs\portfolio`).
2. You can simply double-click `index.html` to open it in your browser.
3. Alternatively, since it's in your XAMPP `htdocs` folder, you can start Apache in the XAMPP Control Panel, then open your browser and navigate to: `http://localhost/portfolio/`.
