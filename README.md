# Azeria Portfolio

A responsive and modern developer portfolio website, built using HTML5, Tailwind CSS, and Vanilla JavaScript.

## 🚀 Key Features

- **Modern & Responsive Design**: Clean UI utilizing glassmorphism, responsive navigation with mobile drawer menu, and micro-animations.
- **Modular Asset Organization**: Custom styles, Tailwind design tokens, and JavaScript logic are cleanly separated into dedicated modules.
- **Dynamic Interactivity**: Mobile menu toggle, active section tracking on scroll, contact form handling, and automatic copyright year.
- **Project Detail Pages**: Dedicated subpages organized under `pages/`.

## 📁 Struktur File & Folder

```text
portofolio-static/
├── assets/
│   ├── css/
│   │   └── style.css            # Custom CSS (glassmorphism, scrollbar, transitions)
│   ├── js/
│   │   ├── tailwind.config.js   # Konfigurasi Tailwind theme, colors, typography
│   │   └── main.js              # Interaktivitas (mobile menu, scroll active, form)
│   └── images/
│       └── logo.png             # Logo website dan favicon
├── pages/
│   └── project-detail.html      # Halaman detail proyek
├── CNAME                        # Konfigurasi custom domain (azeria.web.id)
├── index.html                   # Halaman utama portofolio
└── README.md                    # Dokumentasi proyek
```

## 🛠️ Technologies Used

- HTML5 (Semantic Structure & Accessibility)
- Tailwind CSS (via CDN)
- Custom CSS3 (Glassmorphism & animations)
- Vanilla JavaScript (Modular interactivity)
- Google Fonts (Inter & JetBrains Mono)
- Google Material Symbols

## 💻 Cara Menjalankan

1. **Buka Langsung**: Buka file `index.html` langsung di browser favorit Anda.
2. **Via Local Server (XAMPP / Apache)**:
   - Pastikan Apache berjalan di XAMPP Control Panel.
   - Buka browser dan kunjungi: `http://localhost/portofolio-static/`.
