SINTREN AYU V.2

Sistem Informasi Nelayan Terpadu & Pemetaan Geospasial Wilayah Pesisir Kabupaten Indramayu

Leaflet.js WebGIS & GeoJSON PHP / CodeIgniter 4 MySQL Database BMKG Weather API DomPDF & PHPWord

Ringkasan Proyek

SINTREN AYU V.2 (Sistem Informasi Nelayan Terpadu Indramayu Ayu) adalah sistem informasi terpadu berbasis web dan spasial (WebGIS) yang dikembangkan untuk pemerintah Kabupaten Indramayu (Dinas Perikanan dan Kelautan). Platform ini mengintegrasikan pendataan profil kelompok nelayan pesisir, validasi identitas pelaku usaha KUSUKA, serta pemantauan cuaca maritim secara real-time guna mendukung keselamatan dan kesejahteraan nelayan di wilayah pesisir Indramayu.

Tangkapan Layar Sistem (System Preview)

Peta Sebaran WebGIS

Pemetaan titik kelompok KUB dan Pokmaswas di pesisir Indramayu.

Beranda & Monitoring Cuaca

Suhu real-time, kelembapan, angin, dan prakiraan cuaca 5 hari.

Dashboard Data KUSUKA

Pencatatan profil kelompok nelayan dan ekspor dokumen PDF/Word.

Fitur-Fitur Utama (Key Features)

map

Pemetaan Geospasial Interaktif

Visualisasi titik sebaran KUB (Kelompok Usaha Bersama) dan Pokmaswas (Kelompok Masyarakat Pengawas) di sepanjang pesisir Indramayu dengan layer kontrol dan filter kecamatan.

badge

Integrasi Identitas KUSUKA

Pencatatan dan verifikasi data kelompok nelayan yang terhubung dengan nomor KUSUKA resmi Kementerian Kelautan dan Perikanan (KKP).

thunderstorm

Prakiraan Cuaca Maritim Real-time

Penyajian parameter cuaca perairan terkini (kecepatan angin, kelembapan, suhu) dan tabel prakiraan 5 hari ke depan untuk keselamatan melaut.

print

Ekspor Dokumen Otomatis

Kemudahan cetak dan generate rekapitulasi data anggota dan kelompok nelayan secara instan ke format dokumen PDF dan Microsoft Word.

Teknologi & Arsitektur Sistem

Komponen Teknologi Peran & Implementasi
WebGIS Engine Leaflet.js & Tile Layer Google Maps Rendering peta interaktif, custom marker sebaran (KUB & Pokmaswas), polygon batas wilayah dan tooltip popup.
Backend & Framework PHP / CodeIgniter 4 (CI4) Manajemen controller MVC, routing, otentikasi operator dinas, dan REST API query spasial.
Database MySQL / Spatially Indexed Database Penyimpanan master data nelayan, koordinat latitude/longitude, status verifikasi KUSUKA, dan histori audit.
Layanan Integrasi Weather Data API, DomPDF, PHPWord Sinkronisasi cuaca otomatis per jam serta pembuatan laporan administratif siap cetak.
